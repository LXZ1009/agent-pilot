# Examples: 定价会议逐轮会前访谈

## 示例 1：初始访谈

### 输入

会议：华东大区定价会  
主题：重点客户价格策略与风险提示  
访谈对象：张三，华东大区负责人  
用户目标：开始会前访谈

### 好的输出

```markdown
我们先从最影响本次会议判断的问题开始。

**下一问：**
围绕本次华东大区定价会，你认为当前最需要会议讨论的价格矛盾是什么？请先说 1-3 个最关键的问题。
```

### 不好的输出

```markdown
请张三补充以下信息：
1. 重点客户列表；
2. 当前价格执行情况；
3. 竞品动态；
4. 风险点；
5. 近三个月销量收入毛利率；
6. 下季度预测。
```

原因：这是资料清单，不是逐轮访谈。

## 示例 2：根据回复追问重点客户价格

### 输入

上一轮回复：

```text
目前主要是浙江建投和江苏交工压价比较明显，竞品也在下调。
```

### 好的输出

```markdown
我理解到目前的核心矛盾是：浙江建投、江苏交工压价明显，同时竞品存在降价动作。

**下一问：**
请先补充浙江建投和江苏交工当前实际成交价，以及与官方挂牌价相比大概偏差多少？
```

---

## 示例 3：根据报价追问毛利空间

### 输入

上一轮回复：

```text
浙江建投目前 3850 元/吨，江苏交工 3830 元/吨。
```

### 好的输出

```markdown
目前已经确认了两个重点客户的实际报价，但还无法判断这两个价位是否可接受。

**下一问：**
浙江建投 3850 元/吨、江苏交工 3830 元/吨这两个报价，对应的毛利空间大概是什么水平？是否已经接近成本底线？
```

---

## 示例 4：根据竞品动作追问影响

### 输入

上一轮回复：

```text
竞品近期大概下调了 20 元/吨，江苏交工那边比较敏感。
```

### 好的输出

```markdown
你提到竞品下调约 20 元/吨，并且江苏交工对价格比较敏感。

**下一问：**
这个竞品降价动作已经对江苏交工的采购决策或续约谈判产生影响了吗？如果有，影响程度大概是什么等级？
```

## 示例 5：缺少量化数据时追问

### 输入

已有信息：

- 浙江建投 3850 元/吨；
- 江苏交工 3830 元/吨；
- 竞品下调约 20 元/吨；
- 可能存在客户压价风险。

### 好的输出

```markdown
目前已经收集到重点客户报价和竞品降价信息，但还缺少支撑会议判断的量化经营数据。

**下一问：**
请补充 2026 年 2 月、3 月、4 月华东区域沥青销量数据，单位按吨。如果暂时没有完整数据，也请说明数据负责人或预计补充时间。
```

## 示例 6：建议进入物料整理阶段

### 输入

已有信息：

- 本次会议核心矛盾：重点客户压价与竞品降价；
- 浙江建投和江苏交工报价已明确；
- 竞品降价影响已说明；
- 主要风险已识别；
- 区域负责人给出了初步策略建议；
- 近三个月数据暂缺，但已明确由销售补充。

### 好的输出

```markdown
目前访谈信息已经基本覆盖本次会议需要的核心问题、重点客户价格、竞品影响和风险判断。

**当前判断：**
可以建议主 Agent 进入物料整理阶段。近 3 个月销量、收入和毛利率数据仍可作为待补充项，在物料整理时单独标注。
```

注意：不要声称已经生成 Markdown 文件，也不要声称已写入物料路径。
